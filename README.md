# Damascus Governorate (DG)

Analysis work for the Damascus Governorate project. Kept separate from NIB:
nothing from `nib-org-chart` belongs here, and nothing from here belongs there.

## Layout

    incoming/<YYYY-MM-DD>/   files as received from the client, unchanged
    analysis/                findings, notes and outputs derived from them

Files in `incoming/` are the record of what was received and when. They are
never edited in place; anything derived goes under `analysis/`.
